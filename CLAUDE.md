# Квартира — трекер: правила работы

## Достоверность данных (инструкция владельца, обязательна)
- Всегда ищи и проверяй **подтверждённую** информацию, прежде чем делать вывод или вносить его в сайт/отчёты.
- **Не делай выводов по аналогии.** Пример ошибки: «ЖК Element построил BAZIS-A, значит программа «Тамаша» действует и там» —
  неверно, Element нет в списке программы. Участие ЖК в программе засчитывается только если ЖК прямо указан в источнике.
- Если подтверждения нет — так и пиши: «не подтверждено», «уточнить в банке/у застройщика». Не выдавай предположение за факт.
- У каждого факта о банках, ставках и программах должен быть источник и дата проверки (`source`, `checkedAt` в `src/config/banks.ts`).
- Если источники расходятся — показывай расхождение, в расчётах бери консервативное значение (верхнюю границу ставки).

## Проект
- Сайт: Vite + React + TS (`src/`), деплой на GitHub Pages через Actions. Сборщик Krisha — `scraper/` (Python), данные — `public/data/listings.json`.
- Ипотечные программы и реестр партнёрских предложений — `src/config/banks.ts`; страница «Банки» (`#/programs`).
- Разбор Claude уходит в Telegram через ветку `outbox` (файл `outbox/telegram.html`, workflow `telegram-outbox.yml`), токен только в секретах GitHub.
- Тесты: `npm test`, `python -m unittest scraper.test_scraper`. Скриншоты: `node scripts/screenshots.mjs <папка>`.
- Финансы семьи (ориентиры): взнос ≈ 43 млн, доход 1,77 млн/мес, обязательства 300 тыс/мес, оба — сотрудники и зарплатные клиенты БЦК.
