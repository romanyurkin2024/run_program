- **Карта и граница «рядом с MEGA».** Сейчас «рядом» — список ЖК и диапазоны домов по улицам в `config/area.json`
  (подобраны вручную, на карте не проверены). Идея: геокодировать адреса (OpenStreetMap Nominatim, с кэшем,
  неточные — «координаты не определены»), считать «рядом» кругом вокруг MEGA Alma-Ata с радиусом-ползунком
  (по умолчанию ~1,5 км) + ручной список ЖК; вкладка «Карта» с кругом и точками квартир.
- **Сбор с etagi.com («Этажи», Алматы).** Нужна точная ссылка, которая открывается у владельца (`almaty.etagi.com`
  у нас не резолвится). Варианты: закладка «В трекер» для страниц etagi или ежедневный сбор — только если
  robots.txt и правила сайта разрешают и нет капчи; запуск через GitHub Actions требует разрешения владельца.
- **ATRIA и AL’FARABI 27 в «рядом с MEGA»** — решить при пересмотре границ (сейчас видны через фильтр ЖК или «Весь район»).

  запланированной задачи «Квартира: утренний разбор» (иначе пуш в ветку `outbox` получает 403).
